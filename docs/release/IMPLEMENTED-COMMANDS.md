## Interpretation

- `static` key mode means key positions come from the registered command metadata.
- `dynamic` means runtime key discovery is required, such as EVAL/FCALL, SORT, MIGRATE, XREAD, or multi-pop/algebra commands.
- Cluster routing labels describe how the current router treats the command's discovered keys; they are not a claim of exhaustive Redis Cluster parity.
- ACL categories and flags are the metadata exposed by SnugKV's current COMMAND/ACL compatibility layer.
